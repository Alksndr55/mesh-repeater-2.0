# Проверка сохранённых схем и плат A3

Текущая A3 использует отдельные проверки. Скрипты и отчёты A1/A2 сохраняют свою редакцию: прежний `verify_v2_final_artifacts.py` и результат A2 499/499 нельзя применять как подтверждение новой A3.

Точки входа для окончательного снимка: [итоговая сводка](../audit/a3_2026_10_13/A3_FINAL_CHECKS.json), [независимый отчёт](../audit/a3_2026_10_13/independent/independent_final.json), [обзор A3](../output/V2_OVERVIEW_RU.html). Результат относится только к перечисленным там входным SHA256.

Зафиксированные результаты собственных проверок A3: схемный граф 81/81, native-парность 57/57; ERC POWER/LOGIC — 0. Native DRC POWER/LOGIC/SHIELD имеет по 0 нарушений, неразведённых цепей, расхождений схемы и исключённых проверок. BOM содержит 179 позиций и полностью учитывает исходный состав с разрешёнными изменениями. Отсутствие нерешённых ссылок выбора модели в BOM не подтверждает наличие деталей в продаже.

Свежий независимый аудит завершён: 110/110; входные CAD, правила и библиотеки не изменились за время проверки. Итоговая приёмка подтвердила SHA256 входов, отчётов и экспортов, включая STEP/gzip, сборку и изображения A3. В номинальной сборочной модели три проверки попарных пересечений дали 0 мм³, восемь проверок зазоров до крепежа пройдены.

База сравнения — неизменный `design/v2_electrical_contract.json` и локальная копия S4.16. Добавление INA219 описано `design/feature_ina219_vertical.json`, разрешённые изменения A3 — `design/feature_a3_single_face_split_power.json`. Вторая запись не заменяет первую или исходный контракт.

## Экспорт схем

Запуск из `Meshcore/v2` в PowerShell; Python может быть обычным, KiCad CLI должен быть установлен. При одновременной работе над размещением используйте `--preserve-model`: он не перезаписывает координаты model.json. После изменения состава/листов владелец модели отдельно объединяет актуальные `schematic_uuid` и `sheet_path`.

```powershell
python tools/cad/build_v2_a3_schematics.py --project design/MeshRepeater2_Power --board POWER --export --preserve-model
python tools/cad/build_v2_a3_schematics.py --project design/MeshRepeater2_Logic --board LOGIC --export --preserve-model
```

Нативные XML/ERC помещаются в `audit/a3_2026_10_13/schematic/POWER` и `LOGIC`. PDF: `output/pdf/MeshRepeater2_Power_A3_schematic.pdf` и `MeshRepeater2_Logic_A3_schematic.pdf`. Экспорт не изменяет PCB. Повторная генерация схем меняет их экспортные хеши; после неё заново выполняют проверку графа и актуальности отчётов.

## Схемный граф и FakeTec

```powershell
python tools/cad/verify_v2_a3_schematic_equivalence.py --contract design/v2_electrical_contract.json --power-netlist audit/a3_2026_10_13/schematic/POWER/netlist.xml --logic-netlist audit/a3_2026_10_13/schematic/LOGIC/netlist.xml --power-model design/MeshRepeater2_Power/model.json --logic-model design/MeshRepeater2_Logic/model.json --cable design/interboard_cable.json --out audit/a3_2026_10_13/schematic/combined_equivalence.json
```

Проверяются реальные локальные группы выводов native XML против сохранённых моделей, исходные имена/типы физических выводов M1/M2 и GPIO FakeTec, все исходные Fit/Value-варианты и MPN неизменённых электрических деталей. Отдельно проверяются новые 2512 MPN, неизменная калибровка INA219 0,1 Ом, POWER J11, медная звезда NT2, выделенный ввод RADIO к FB1 и модемная нагрузка после FB1.

Для сравнения с S4.16 только в отдельной копии общего графа объединяют новый измерительный R71 и медную звезду NT2; идентичность J11 переносится с LOGIC на POWER. Сохранённые физические сети BAT/BAT_SYS не объединяются. SYS_3V3 и RADIO_3V3 остаются отдельными именованными трассируемыми ветвями, которые физически сходятся в NT2. R56 сохраняет 1,8 Ом / 0 Ом, отображение мощности обновлено с прежнего 0,125 Вт на фактический 1 Вт выбранного 2512.

Оригинальный native netlist: `audit/source_s4_16/native_netlist.xml`, SHA256 `14b479e30ab779ca2c8af2465e6ccee1ccf8aeb26e435c4c3a84bb1cc51662d3`. Рабочая версия 1.0 не используется как зависимость.

## Сохранённые PCB

Запускать Python соответствующей версии KiCad с модулем pcbnew:

```powershell
& 'C:/Program Files/KiCad/10.0/bin/python.exe' tools/verify_v2_a3_native_boards.py
```

Проверка читает PCB, model.json и XML обоих проектов. Сверяются фактические reference/pin, группы назначенных медных сетей, координаты/углы, значения и текущие идентификаторы посадок. Подтверждаются одна F.Cu-сторона компонентов POWER, шесть согласованных 2512, ряд TP1/TP6/TP9, сегменты дорожек 0/45/90 градусов и отсутствие прежних сносок Gxx x1.5. Сохраняется `audit/a3_2026_10_13/native_board_parity.json` с хешами входов. Платы, модели и библиотеки скрипт не изменяет.

Физические посадки проверяют раздельно: R1/R40/R41/R55 — Vishay WSL2512, площадки 1,65×3,68 мм / шаг 5,71 мм; R56/R71 — стандартные 2512 для выбранных Yageo. Одинаковый размер корпуса не означает одинаковый рекомендуемый рисунок меди.

Это проверка назначений и геометрии сегментов. Физические маршруты, отсутствие неразведённых цепей, коротких замыканий и обхода J11/R71 подтверждают отдельно native DRC и анализ связности меди. Читаемость маркировки, сечение силовых цепей, RF/GND и зазоры сборки также имеют отдельные отчёты. Такой CAD-контроль не является стендовым измерением EMI, нагрева или работоспособности реального клона.

## BOM

```powershell
python tools/build_v2_a3_component_bom.py
```

Актуальная таблица A3 — `bom/V2_A3_COMPONENT_BOM.csv`. Для шести 2512 скрипт использует новые реальные библиотечные IDs и выбранные MPN; старые доказательства неизменной геометрии 1206 к ним не применяет. NT2 — медь платы, не закупаемая деталь. Для новых MPN не подтверждены актуальные местные цены/наличие.

Каждый итоговый отчёт действителен только при совпадении собственных входных хешей с окончательно сохранёнными файлами. После финальной трассировки, маркировки, обновления библиотеки или моделей нужны свежие прогоны и экспорты.

## Независимый аудит и итог

Аудитор запускает `audit/a3_2026_10_13/independent/verify_a3_independent.py` только после получения манифеста `ALL_CAD_FROZEN.json`. Он заново читает реальные native PCB, схемы, библиотеки и правила; выполняет собственные DRC/ERC/XML, анализ широких силовых путей, геометрию тестовых площадок, маркировки и окна экрана. Хеши CAD до и после должны совпасть. Проверяется сохранение GPIO и ISP, медная звезда NT2, единственная J11 и отсутствие её обхода. Номинальное прохождение пластика через окно не доказывает допуски купленного разъёма.

`tools/build_v2_a3_overview.py` создаёт `A3_FINAL_CHECKS.json` и обновляет обзор только после успешных схемного графа, native-парности и независимого аудита. Скрипт сверяет SHA256 их входов и свежих экспортов, нулевые DRC и актуальность BOM. Это проверка сохранённого CAD; испытания устройства перечислены в [V2_LIMITATIONS_RU.md](V2_LIMITATIONS_RU.md).
